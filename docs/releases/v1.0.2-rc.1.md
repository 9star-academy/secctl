# v1.0.2-rc.1 — Linux 验收预发布

本版本用于空白 Linux 测试服务器验收。尚未完成真实网络、Docker/整机重启与 SSH 挂断回滚的完整实机验收，不作为生产稳定版推荐。

## 本次更新

- SSH 修改前校验配置、公钥与有效配置结果；创建独立 systemd 回滚定时器，未确认或操作失败时恢复原配置。确认时输入 `confirm`。
- 修正防火墙 deny 和重复规则优先级；缺少真实后端或执行失败时返回错误，不再使用成功的模拟后端兜底。
- Docker Shield 加入实际过滤链、UFW 转发授权、运行状态检查和 Docker 重启挂接。
- 修正监听审计的未知状态和 IPv6 回环地址判断，不再将监听地址直接等同于公网可达。
- 安装器新增 SHA256 校验；发布包包含 Linux/macOS amd64/arm64 二进制和 `SHA256SUMS`。

## 安装此验收版本

```bash
curl -fsSL https://raw.githubusercontent.com/9star-academy/secctl/v1.0.2-rc.1/scripts/install.sh | sudo env SECCTL_VERSION=v1.0.2-rc.1 bash
secctl --version
```

预期显示 `secctl version v1.0.2-rc.1`。本版本为预发布，必须显式指定 `SECCTL_VERSION`。

## 验收范围

优先在无业务的 Ubuntu/Debian systemd 虚拟机验收，保留云控制台入口。Docker Shield 需要已启用 UFW、`MANAGE_BUILTINS=no`、Docker iptables 后端和默认 IPv4 bridge 网桥。容器端口使用 `secctl allow <容器端口>/tcp --docker` 授权。

自动 IP 封禁、独立白名单管理、IPv6 容器和 Docker 原生 nftables 后端尚不支持。复杂 SSH Match/Include 配置会明确拒绝自动修改。SSH 临时回滚定时器不保证跨整机重启恢复；原生 iptables 宿主机规则不自动持久化。
